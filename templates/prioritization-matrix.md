# Prioritization Matrix

## Purpose

Rank opportunities, features, or backlog items transparently against a consistent method, tied to the outcome you are trying to move. The matrix makes the trade-offs visible so scope decisions are defensible rather than driven by whoever asked last. Pick one primary method for a given decision and apply it consistently.

## Method selection

- RICE: for comparing many items on expected value per unit of effort.
- Value vs Effort: for quick, coarse triage.
- Kano: to balance basic, performance, and delight needs.
- MoSCoW: for scope agreement (Must, Should, Could, Won't now).
- WSJF: for flow-based prioritisation (cost of delay divided by job size).

Whichever you use, tie the ranking back to the north-star outcome.

## RICE scoring

RICE score is Reach times Impact times Confidence, divided by Effort.

| ID | Item | Reach | Impact | Confidence | Effort | RICE score | Rank |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ITEM-001 |  |  |  |  |  |  |  |

Scoring guidance: Reach is the number of users or events affected in a period; Impact is a rated effect on the outcome (for example 3 massive, 2 high, 1 medium, 0.5 low); Confidence is a percentage reflecting how sure you are; Effort is person-time. State your scales so scores are comparable.

## Review criteria

- One method is applied consistently across all items in the decision.
- Scores and scales are stated so the ranking is reproducible.
- The ranking ties to the target outcome, not to request order.
- The output is a defensible order, not just scores.
