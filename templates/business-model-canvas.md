# Business Model Canvas

## Purpose

Describe on one page how an enterprise or a proposed venture creates, delivers, and captures value. This is the BABOK Business Model Canvas technique (10.8). Use it to understand a current model, design a new one, or test whether a change is coherent across all nine building blocks.

## The nine building blocks

Work through all nine. The blocks must fit together: the value propositions serve the customer segments through the channels and relationships, delivered by the key resources, activities, and partnerships, with revenue streams that exceed the cost structure.

| Block | Prompt | Content |
| --- | --- | --- |
| Customer segments | Who are the distinct groups you serve, and which matter most? |  |
| Value propositions | What value do you deliver to each segment, and which problem or job does it address? |  |
| Channels | How do you reach and deliver to each segment (awareness, sale, delivery, support)? |  |
| Customer relationships | What relationship does each segment expect (self-service, personal, community)? |  |
| Revenue streams | How and for what do customers pay, and what is the pricing model? |  |
| Key resources | What assets are essential (people, technology, physical, financial, intangible)? |  |
| Key activities | What must you do well to deliver the value proposition? |  |
| Key partnerships | Which partners and suppliers do you rely on, and why? |  |
| Cost structure | What are the major costs, and are they fixed or variable? |  |

## Coherence check

- Every value proposition maps to at least one customer segment.
- Every segment has a channel, a relationship, and a revenue stream.
- Key resources, activities, and partnerships actually support the value propositions.
- Revenue streams plausibly exceed the cost structure.

## Review criteria

- All nine blocks are completed and internally consistent.
- Customer segments are distinct and prioritised.
- Value propositions are tied to real customer jobs, pains, and gains.
- The model shows how value is captured, not only created and delivered.
