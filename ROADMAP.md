# Roadmap

## Phase 1: Foundation

Status: Done.

- Establish repository structure.
- Define contribution and agent guidance.
- Create initial architecture and methodology documentation.

## Phase 2: Core Skills

Status: Done (43 skills; eight deepened with method playbooks in 1.17.0).

- Build orchestrator and specialist skill packs.
- Define inputs, outputs, and quality gates for each skill.

## Phase 3: Templates and Checklists

Status: Done (80 templates, 5 checklists).

- Add reusable templates for analysis, product, delivery, governance, and review.
- Add quality and readiness checklists.

## Phase 4: Frameworks

Status: Done (6 frameworks).

- Document reusable frameworks for strategy, discovery, prioritization, requirements, and decision-making.

## Phase 5: Domain Packs

Status: In progress (payments ISO 20022, healthcare HL7 FHIR).

- Add domain-specific guidance, terminology, regulations, and example deliverables.

## Phase 6: Evaluation

Status: In progress (a quality profile and rubric for all 80 artefact types; calibration sets for 6 types, provisional).

- Add rubrics, test cases, and repeatable evaluation workflows.

## Phase 7: Examples

Status: In progress (2 worked examples).

- Publish end-to-end examples that demonstrate complete workflows.

## Next

- Confirm the provisional calibration scores with a business analyst reviewer, then add sets for the remaining first-wave artefact types, most-used first.
- Run the skill upgrade program (`docs/skill-upgrade-program.md`) on the remaining skills.
- Add worked examples beyond Requirements Analysis and Design Definition, starting with Strategy Analysis and Solution Evaluation.
- Add domain packs as client work requires them.
