# Contributing

Thank you for contributing to Business Analysis OS.

## Contribution Guidelines

- Keep files focused and reusable.
- Use Markdown for knowledge assets unless another format is required.
- Prefer kebab-case filenames.
- Add documentation near the asset it describes.
- Update related templates, examples, or evaluation criteria when behavior changes.

## Review Checklist

- The contribution fits the repository structure.
- The purpose and intended audience are clear.
- Inputs, outputs, assumptions, and quality criteria are documented when relevant.
- Terminology is consistent with surrounding assets.
- The asset can be reused without relying on unstated context.
