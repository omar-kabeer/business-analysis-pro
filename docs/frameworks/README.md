# Frameworks

Reusable analysis and delivery frameworks are consolidated in the top-level `frameworks/` directory, each with purpose, when to use, method, and pitfalls:

- `frameworks/prioritisation.md`: RICE, MoSCoW, Kano, WSJF, value vs effort.
- `frameworks/discovery.md`: Jobs to be Done, opportunity solution tree, continuous discovery.
- `frameworks/strategy.md`: SWOT and TOWS, PESTLE, Five Forces, Business Model and Value Proposition Canvas, OKRs, Balanced Scorecard.
- `frameworks/decision.md`: options analysis, decision matrix, cost of delay.
- `frameworks/requirements-and-delivery.md`: INVEST, definition of ready and done, traceability.
