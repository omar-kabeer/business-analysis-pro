# Architecture Overview

Business Analysis OS is organized as a modular knowledge and delivery system.

## Layers

1. **Guidance layer**: repository instructions, Claude guidance, contribution rules, and roadmap.
2. **Skill layer**: specialist skill packs that define role-specific methods, inputs, outputs, and review criteria.
3. **Method layer**: documented methodologies, frameworks, BABOK guidance, and product-management practices.
4. **Artifact layer**: templates, checklists, deliverables, examples, prompts, and domain packs.
5. **Evaluation layer**: rubrics and tests that validate artifact quality and consistency.

## Design Principles

- Modular assets with clear ownership.
- Traceable movement from business objective to decision, requirement, deliverable, and evaluation result.
- Reusable enterprise formats rather than one-off prompt outputs.
