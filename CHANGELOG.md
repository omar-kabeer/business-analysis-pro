- Phase 3, batch 1: method playbooks for the ten weakest skills, each grounded in the BABOK tasks and techniques it applies, with stop rules, common failures, and a worked example on the supplier invoice scenario: `architecture` (solution architecture), `process-modelling` (process analysis), `product-owner` (backlog management), `governance` (delivery governance), `data-analysis` (measurement and analysis), `communication` (stakeholder communication), `market-research` (market analysis), `business-intelligence` (BI delivery), `data-modelling`, and `information-management`. Each skill links its playbook. The validator checks the ownership file against the profiles and the skills, and fails on a stale section. The depth audit now counts a source that applies to every skill (BABOK) toward each skill's source check.
