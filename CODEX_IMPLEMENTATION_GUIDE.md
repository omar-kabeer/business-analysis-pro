# Codex Implementation Guide

This repository is intended to become an enterprise Business Analysis and Product Management Operating System, not a prompt collection.

## Mission
Build a production-grade repository with modular Claude Skills, reusable methodologies, templates, checklists, frameworks, domain packs, evaluation pipelines, and documentation.

## Principles
- Repository first, prompts second.
- Modular architecture.
- Single responsibility per file.
- Enterprise documentation standards.
- Testable outputs.
- Versioned templates.
- Consistent naming.

## Repository Structure
Create folders for docs, skills, templates, checklists, frameworks, deliverables, domain-packs, prompts, evaluation, examples, memory, and .github assets.

## Deliverables
Implement:
1. Executive orchestrator.
2. 30+ specialist agents.
3. BABOK aligned business analysis knowledge.
4. Product Manager knowledge.
5. Product Owner knowledge.
6. 150+ templates.
7. Evaluation framework.
8. Domain packs including ISO 20022.
9. Comprehensive README and architecture docs.

## Quality Gates
Every generated artifact must be complete, internally consistent, traceable, reusable, professionally formatted, and reviewed before acceptance.
