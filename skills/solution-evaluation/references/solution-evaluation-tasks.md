# Solution Evaluation Tasks (BABOK KA 6)

## Measure Solution Performance (8.1)

Decide how to measure the value the solution should deliver and collect the data. Prefer measures that reflect the business objectives and the business case, not just system metrics. Agree targets and the collection method up front.

## Analyze Performance Measures (8.2)

Interpret the measures to understand the value being delivered. Compare actual to expected. State data quality, recency, and confidence. Look for trends, not just point values, and separate correlation from cause.

## Assess Solution Limitations (8.3)

Find where the solution itself limits value: defects, missing capability, poor usability, performance problems, or a design that does not fit the work. These are things a change to the solution could fix.

## Assess Enterprise Limitations (8.4)

Find where the enterprise around the solution limits value: process not adapted, unclear ownership, culture or incentives that discourage use, missing skills, or policy constraints. A perfect solution can still deliver little value if the enterprise does not use it well. Low adoption is often an enterprise limitation, not a solution defect.

## Recommend Actions to Increase Solution Value (8.5)

Recommend the action that best increases value given the limitations found:

- Adjust or configure the solution.
- Extend it with missing capability.
- Change the surrounding process, structure, or incentives.
- Replace the solution.
- Retire it if it no longer earns its cost.
- Invest further if the value case supports it.

State the expected benefit, the cost and effort, and the trade-offs, and hand financial modelling to the finance skill.

## Closing the loop

Solution evaluation feeds the next cycle of change: a limitation becomes a new business need, which re-enters strategy analysis. Benefits realisation against the original business case is a natural output.
