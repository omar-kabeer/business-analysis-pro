# Solution Evaluation Skill

## Role

Assess the performance and value of a solution in use, and recommend how to increase it. This is BABOK knowledge area 6 (Solution Evaluation): measure performance, analyse the measures, find what limits value in the solution and in the enterprise around it, and recommend action.

## Inputs

- The solution in use, the objectives and business case it was meant to serve, and the value it should deliver.
- Performance data, usage data, and stakeholder feedback.
- The decision the evaluation must inform (continue, adjust, replace, retire, or invest more).

## Workflow

Follow the knowledge-area tasks (see `references/solution-evaluation-tasks.md`):

1. Measure solution performance: agree the measures that reflect the intended value and collect the data. Tie them back to the original objectives and business case.
2. Analyse the performance measures: interpret them honestly, comparing actual value to expected, and note data quality and confidence.
3. Assess solution limitations: find where the solution itself limits value (defects, gaps, poor usability, missing capability).
4. Assess enterprise limitations: find where the surrounding enterprise limits value (process, structure, culture, policy, skills, incentives).
5. Recommend actions to increase value: adjust, extend, replace, retire, or invest further, with the expected benefit and the trade-offs.

## Outputs

- Solution performance measures against the intended value and business case.
- An analysis of the value being delivered, with solution and enterprise limitations named.
- Prioritised recommendations to increase value, with expected benefit and trade-offs.

## Quality gates

- Measures tie back to the original objectives and business case, not to convenient numbers.
- Analysis states data quality and confidence and does not confuse correlation with cause.
- Both solution and enterprise limitations are considered; the fix is not assumed to be in the solution alone.
- Recommendations are evidence-based with expected benefit and trade-offs.

## Done when

Performance is measured against intended value, limitations in the solution and the enterprise are identified, and prioritised, evidence-based recommendations to increase value are delivered.
