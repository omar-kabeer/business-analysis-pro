# Normative sources for the procurement-contracts skill

Conformance authorities, not citation sources. Judge an artefact by whether it passes the checks, not by whether it cites the standard. Do not quote the standards in deliverables.

Resolve each source id against `sources/manifest.json` and read its checks in `sources/conformance/<source-id>.md`.

## procurement-document

- `iso-20400`. ISO 20400:2017, sustainable procurement guidance. A procurement document must pass the ISO20400-PD blocking checks: it defines documented sustainability criteria; the criteria reflect the sourcing-strategy priorities; and each sustainability requirement is verifiable through an evaluation procedure named in the tender documents. Advisory checks cover minimum-versus-optional requirements and fair opportunity to compete. Note: ISO 20400 is guidance ("should"), so the blocking severities are our house gate.
