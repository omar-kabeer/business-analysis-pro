# List of Ideas / Themes for Analysis Evaluation Rubric

A repeatable rubric for judging whether a brainstorming output is a useful set of ideas. The output is a list of ideas or themes generated for further analysis. Used by the elicitation skill. Based on BABOK Brainstorming (10.5).

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Volume | A sufficient volume of ideas was generated for the topic. |
| 2 | On topic | The ideas address the question the session was run for. |
| 3 | Captured | The ideas are captured clearly and completely. |
| 4 | De-duplicated | Duplicate ideas are merged. |
| 5 | Themed | The ideas are grouped into themes where useful. |
| 6 | Non-judgemental capture | Ideas were captured without premature filtering, per the technique. |
| 7 | Actionable | The list feeds the next analysis or prioritization step. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the elicitation skill.
