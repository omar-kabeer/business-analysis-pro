# Metadata Definitions Evaluation Rubric

A repeatable rubric for judging whether metadata definitions are complete and consistent. Metadata definitions describe the meaning, origin, and rules of the data used by a solution. Used by the business-intelligence and information-management skills. Based on BABOK Business Intelligence Perspective (11.2).

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Definitions | Each data element has a business and technical definition. |
| 2 | Origin | The source and lineage of each element are recorded. |
| 3 | Rules | Validation, transformation, and quality rules are captured. |
| 4 | Consistent | The metadata is consistent with the data dictionary and models. |
| 5 | Single source | Each element is defined once, without conflicting definitions. |
| 6 | Ownership | Each element has a data owner or steward. |
| 7 | Complete | The metadata covers the elements the solution uses. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the information-management skill.
