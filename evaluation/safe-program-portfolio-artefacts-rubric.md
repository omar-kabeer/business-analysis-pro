# SAFe Program / Portfolio Artefacts Evaluation Rubric

A repeatable rubric for judging whether scaled-agile program and portfolio artefacts are used soundly. These artefacts, from a framework such as SAFe, coordinate work across teams at the program and portfolio level. Used by the agile-coach skill. Based on BABOK Agile Perspective (11.1). Treat the framework as a reference standard to apply, not to reproduce.

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Right artefact | The artefact chosen fits the level, whether team, program, or portfolio. |
| 2 | Framework fidelity | The artefact follows the framework's intent, not just its labels. |
| 3 | Alignment | The artefact aligns program and portfolio work to strategy. |
| 4 | Coordination | It coordinates dependencies across teams. |
| 5 | Applicability | The framework element is applied because it fits, not by rote. |
| 6 | Currency | The artefact reflects the current version of the framework in use. |
| 7 | Lightweight | The artefact stays as light as the coordination need allows. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the agile-coach skill.
