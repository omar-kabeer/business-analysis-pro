# Enterprise Core Diagram Evaluation Rubric

A repeatable rubric for judging whether an enterprise core diagram captures the operating foundation soundly. An enterprise core diagram shows the core processes, data, and technologies that form the operating foundation for execution. Used by the business-architecture skill. Based on BABOK Business Architecture Perspective (11.4).

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Core processes | The core business processes are shown. |
| 2 | Shared data | The shared data the core relies on is shown. |
| 3 | Key technologies | The enabling technologies or systems are shown. |
| 4 | Customers | The key customers or entities served are shown. |
| 5 | Coherent | The elements fit together as an operating foundation. |
| 6 | Right altitude | The diagram stays at the enterprise level, not process detail. |
| 7 | Readable | The diagram is legible and can be used unaided. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the business-architecture skill.
