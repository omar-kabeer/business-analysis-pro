# Reference Models and Frameworks Evaluation Rubric

A repeatable rubric for judging whether a reference model or framework is applied soundly. Reference models and frameworks, such as APQC PCF, SCOR, TOGAF, or Zachman, provide predefined architectural templates to adapt. Used by the business-architecture skill. Based on BABOK Business Architecture Perspective (11.4). Adapt the reference, do not reproduce it.

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Right model | The reference model chosen fits the industry or function. |
| 2 | Applicability | The model is applied because it fits, not by default. |
| 3 | Adapted | The model is adapted to the organization, not copied wholesale. |
| 4 | Currency | The version used is current and cited. |
| 5 | Coverage | The parts of the model used cover the need. |
| 6 | Consistent | The adapted model is consistent with the organization's own architecture. |
| 7 | Attribution | The source framework is attributed and used within its license. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the business-architecture skill.
