# Root Cause Analysis Evaluation Rubric

A repeatable rubric for judging whether a root cause analysis reaches the real cause of a problem. Root cause analysis, using techniques such as the five whys or a fishbone diagram, traces a problem to its underlying causes. Used by the quality and business-analysis skills. Based on BABOK Root Cause Analysis (10.40).

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Problem defined | The problem being analysed is stated clearly. |
| 2 | Causes not symptoms | The analysis distinguishes causes from symptoms. |
| 3 | Depth | The analysis reaches root causes, not just the first-level cause. |
| 4 | Evidence | The causes are supported by evidence. |
| 5 | Method | A recognized method is applied systematically. |
| 6 | Completeness | The main causal paths are explored, with none obviously missed. |
| 7 | Actionable | The root causes identified can be acted on. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the quality skill.
