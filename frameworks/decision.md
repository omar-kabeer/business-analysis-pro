# Decision Frameworks

Frameworks for choosing between options with the trade-offs visible. Used by the strategy, finance, and governance skills and the `decision-log` template.

## Options analysis

- Purpose: choose among genuinely distinct options.
- When to use: any significant decision, including the do-nothing option.
- Method: define real alternatives, score each against explicit criteria (strategic fit, value, feasibility, risk, cost), and state the conditions under which the ranking would flip.
- Pitfalls: one option dressed as several; criteria chosen to favour a preferred answer.

## Decision matrix

- Purpose: compare options on weighted criteria.
- When to use: a structured, defensible choice.
- Method: list criteria, assign weights that sum to 100, score each option per criterion on an agreed scale, multiply by weight, and sum. Set weights before scoring.
- Pitfalls: tuning weights to the desired winner; scoring without evidence.

## Cost of delay

- Purpose: value the timing of a decision or delivery.
- When to use: sequencing work where being late has a cost.
- Method: estimate the value lost per unit of time an item is delayed. Combine with job size for WSJF.
- Pitfalls: precise-looking numbers on rough estimates; treat as relative.
