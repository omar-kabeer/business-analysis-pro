# Discovery Kickoff

Use this when the problem is still fuzzy and you need to frame it before analysis.

## Prompt

`/business-analysis-os:elicitation`

Help me run discovery on this: [describe the problem area and what triggered it].

Known stakeholders: [list]
What I already assume: [list]

Please produce a discovery plan, interview questions or a workshop agenda as appropriate, and a structured list of assumptions and unknowns to confirm. Frame the real problem with the BACCM before proposing solutions.
