# Review Request

Use this to get a deliverable independently verified or critiqued before it goes out.

## Prompt

Please review this deliverable before I share it: [paste or reference the file].

For requirements, a BRD, or a spec, use the requirements-verifier agent or the quality skill and grade it against the matching rubric.
For a proposal, business case, or executive summary, use the deliverable-critic agent or the executive-review skill and read it as the decision maker would.

Return a verdict, a findings list by severity with specific fixes, and the weakest points to strengthen first.
