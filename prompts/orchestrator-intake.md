# Orchestrator Intake

Use this to hand an unstructured request to the orchestrator so it frames the problem and routes it.

## Prompt

`/business-analysis-os:orchestrator`

I have a request I need help turning into structured analysis and deliverables.

Request: [paste the raw request or problem]

Context I know: [stakeholders, constraints, timeline, systems, domain]
Decision or output I need: [for example a business case, a BRD, a recommendation]

Please classify this, tell me the approach and which skills you will use, then proceed. State assumptions and flag anything you need from me.
