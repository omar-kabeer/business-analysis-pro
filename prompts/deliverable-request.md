# Deliverable Request

Use this to ask for a specific deliverable from the right skill, built on the matching template.

## Prompt

I need a [deliverable, for example a business case / BRD / PRD / process model].

Inputs: [paste the source material, notes, or prior analysis]
Audience and purpose: [who reads it and the decision it supports]
Constraints: [budget, regulatory, technical]

Use the matching template from the OS, fill it from the inputs, state assumptions for anything missing, and run the natural-prose-editor pass with no em dashes. When done, tell me what would strengthen it.
