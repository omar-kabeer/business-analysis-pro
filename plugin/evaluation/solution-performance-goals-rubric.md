# Solution Performance Goals Evaluation Rubric

A repeatable rubric for judging whether solution performance goals are set well enough to measure a solution against. Performance goals define the level of performance the solution is expected to reach, aligned to how the organization defines value. Used by the solution-evaluation and quality skills. Based on BABOK Measure Solution Performance (8.1).

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Aligned to objectives | The goals align with the business objectives and enterprise measures. |
| 2 | Measurable | Each goal is measurable. |
| 3 | Target | Each goal has a target and, where useful, a baseline. |
| 4 | Relevant | The goals reflect how the organization defines value for this solution. |
| 5 | Achievable | Each goal is realistic for the solution. |
| 6 | Owned | Accountability for each goal is assigned. |
| 7 | Time-bound | The period in which each goal is to be reached is stated. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the solution-evaluation skill.
