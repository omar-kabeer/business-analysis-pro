# Process Analysis Findings / Improvement Recommendations Evaluation Rubric

A repeatable rubric for judging whether process analysis findings are evidenced and actionable. The findings identify where a process underperforms and recommend improvements. Used by the process-modelling and business-analysis skills. Based on BABOK Process Analysis (10.34).

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Baseline | The current process performance is described as a baseline. |
| 2 | Bottlenecks evidenced | Bottlenecks and waste are identified with evidence. |
| 3 | Root cause | The cause of each issue is understood, not just the symptom. |
| 4 | Improvements | Improvements are proposed for the issues found. |
| 5 | Quantified | The expected benefit of each improvement is quantified where possible. |
| 6 | Feasible | The improvements are feasible within the constraints. |
| 7 | Prioritised | The improvements are prioritised by value or effort. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the process-modelling skill.
