# User Acceptance Test (UAT) Evaluation Rubric

A repeatable rubric for judging whether user acceptance testing confirms the solution meets user needs. UAT assesses whether the delivered solution meets the needs of the stakeholder group that will use it, validated against acceptance criteria. Used by the acceptance-testing and quality skills. Based on BABOK acceptance testing practice.

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Acceptance criteria | The test cases are derived from the acceptance criteria. |
| 2 | Coverage | The test cases cover the requirements and key user flows. |
| 3 | Real users | The tests are run by the users who will use the solution. |
| 4 | Results recorded | Each test case has a recorded pass or fail with evidence. |
| 5 | Defects logged | Failures are logged as defects, classified, and tracked. |
| 6 | Environment | The tests run in a realistic environment and data set. |
| 7 | Sign-off | The basis for acceptance sign-off is clear. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the acceptance-testing skill.
