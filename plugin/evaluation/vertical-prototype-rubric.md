# Vertical Prototype Evaluation Rubric

A repeatable rubric for judging whether a vertical prototype explores one function in real depth. A vertical prototype builds a deep slice through one function, from interface to data, to test it thoroughly. Used by the prototyping and architecture skills. Based on BABOK Prototyping (10.36).

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Depth | The prototype goes deep through the layers of the one function it covers. |
| 2 | Function chosen | The function chosen is the one worth exploring in depth, such as the riskiest or least understood. |
| 3 | Realistic | The slice is realistic enough to reveal genuine issues. |
| 4 | Requirements traceable | The functionality traces to the requirements it realizes. |
| 5 | Findings | The prototype surfaces findings about feasibility or design. |
| 6 | Scope clear | It is clear that only one function is represented. |
| 7 | Feedback captured | Feedback on the function is captured and fed back. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the prototyping skill.
