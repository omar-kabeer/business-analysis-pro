# Value Chain Evaluation Rubric

A repeatable rubric for judging whether a value chain represents how an organization creates value. A value chain shows the primary and support activities through which an organization delivers value to customers. Used by the business-architecture and visual-modelling skills. Based on BABOK Business Capability Analysis and business architecture practice.

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Primary activities | The primary, value-adding activities are identified in sequence. |
| 2 | Support activities | The support activities that enable the primary ones are identified. |
| 3 | End to end | The chain runs end to end, from input to the value delivered to the customer. |
| 4 | Value focus | Each activity is framed by the value it adds, not just the task. |
| 5 | Completeness | No major activity is missing from the chain. |
| 6 | Alignment | The chain aligns with the organization's capabilities and strategy. |
| 7 | Readable | The diagram is legible and labelled so a reader can use it unaided. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the business-architecture skill.
