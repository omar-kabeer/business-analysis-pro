# Interface List / Interface Specifications Evaluation Rubric

A repeatable rubric for judging whether interfaces are identified and specified completely. An interface list and its specifications describe the interfaces between the solution and other systems, people, and processes. Used by the architecture and requirements skills. Based on BABOK Interface Analysis (10.24).

## Scoring scale

For each dimension score 0 to 3: 0 absent, 1 weak, 2 adequate, 3 strong.

## Dimensions

| # | Dimension | What good looks like |
| --- | --- | --- |
| 1 | Interfaces identified | All interfaces, whether system, human, or process, are identified. |
| 2 | Inputs and outputs | The inputs and outputs of each interface are defined. |
| 3 | Triggers | The events or triggers for each interface are stated. |
| 4 | Data and format | The data exchanged and its format are specified. |
| 5 | Frequency and volume | The frequency and volume of exchange are stated where they matter. |
| 6 | Error handling | How errors and exceptions are handled is defined. |
| 7 | Complete | No interface the solution needs is missing. |

## Result

Total the scores (maximum 21):

- Pass: 17 or higher with no dimension at 0.
- Pass with changes: 12 to 16, or a single quick-to-fix dimension at 1.
- Fail: below 12, or any dimension at 0.

Record findings by severity with a specific fix, and route material issues back to the architecture skill.
