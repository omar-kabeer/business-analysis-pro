# Prioritization Matrix: Portal Release 1

Decision: which features form release 1. Candidates: all six items tagged "release 1 candidate" on 20 June.
Outcome: raise self-service status answers from 0 to 60 percent in 12 months.
Method: RICE, because items differ widely in reach and effort and we have data for both.
Scales: Reach is suppliers per quarter (AP call log); Impact 3, 2, 1, or 0.5 on self-service answers; Confidence 100, 80, or 50 percent; Effort in team weeks from refinement.

ITEM-001 Status lookup: 1,800 x 3 x 0.8 / 4 = 1,080. Rank 1.
ITEM-002 Expected payment date: 1,500 (estimate) x 2 x 0.5 / 3 = 500. Rank 2.
ITEM-003 Remittance download: 600 x 1 x 0.8 / 2 = 240. Rank 3.
(ITEM-004 to ITEM-006 scored the same way; ranks 4 to 6.)

Decision: release 1 is ITEM-001 and ITEM-002, which together cover 85 percent of status calls. No overrides.
A-031: Treasury dates are accurate enough to show; if not, ITEM-002 impact drops and we re-rank.
