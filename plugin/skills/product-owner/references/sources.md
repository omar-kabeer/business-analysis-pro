# Normative sources for the product-owner skill

Conformance authorities, not citation sources. Judge an artefact by whether it passes the checks, not by whether it cites the standard. Do not quote the standards in deliverables.

Resolve each source id against `sources/manifest.json` and read its checks in `sources/conformance/<source-id>.md`.

## product-backlog

- `scrum-guide-2020`. The Scrum Guide (November 2020). A Product Backlog must pass the SCRUM-PB blocking checks: it is an ordered list of items to improve the product, and it contains a Product Goal its items emerge to fulfil. Advisory checks cover refinement of near-term items and backlog transparency. Also relevant to `agile-coach`.

## sprint-artefact

- `scrum-guide-2020`. The Scrum Guide (November 2020). The Sprint artefacts must pass the SCRUM-SA blocking checks: the Sprint Backlog has a Sprint Goal (why), selected items (what), and a delivery plan (how); a single Sprint Goal finalized at Sprint Planning; a Definition of Done exists; and the Increment consists only of work meeting the Definition of Done. Advisory checks cover Increment usability and keeping the Sprint Backlog current. The Scrum Guide defines the framework as immutable, so these are conformance-to-Scrum gates.
