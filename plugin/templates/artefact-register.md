# Artefact Register

## Purpose

Hold the authoritative list of everything the initiative produces: what it is called, what class it belongs to, who owns it, where it lives, which version is current, and whether it is baselined. It is the index that makes every other artefact findable.

## Conventions

| Convention | Value |
| --- | --- |
| ID pattern | CLASS-INITIATIVE-NNN, for example REQ-PAY-014 |
| Naming pattern | Lowercase, hyphenated, content-descriptive, no version in the filename |
| Version trigger | Any meaningful edit |
| Baseline trigger | Approval at a defined checkpoint |
| Supersession | Status set to superseded, with a pointer to the replacement; IDs are never reused |
