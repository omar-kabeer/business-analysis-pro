# Solution Performance Analysis

## Purpose

Analyse the performance measurements collected against the goals, and recommend how to close gaps and leverage opportunities. This is the working form of the BABOK Analyze Performance Measures task (8.2) and its output, the Solution Performance Analysis.

## 2. Drivers and root causes

Identify the drivers of the performance and the root causes of any variance.

## 3. Conclusions

State the conclusions the data supports, and acknowledge the uncertainty in it.

## 4. Recommendations

Recommend how to solve the performance gaps and leverage the opportunities. Evaluate a completed analysis with `evaluation/solution-performance-analysis-rubric.md`.
