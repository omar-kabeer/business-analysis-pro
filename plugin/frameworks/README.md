# Frameworks

Reusable analysis and delivery frameworks, defined once and referenced by many skills and templates. Each file follows the same shape: purpose, when to use, method, and pitfalls. These consolidate framework content that also appears in individual skill references, so there is a single canonical place to point to.

- `prioritisation.md`: RICE, MoSCoW, Kano, WSJF, value vs effort.
- `discovery.md`: Jobs to be Done, opportunity solution tree, continuous discovery.
- `strategy.md`: SWOT, PESTLE, Porter's Five Forces, Business Model Canvas, Value Proposition Canvas, OKRs, Balanced Scorecard.
- `decision.md`: options analysis, decision matrix, cost of delay.
- `requirements-and-delivery.md`: INVEST, definition of ready and done, traceability.
