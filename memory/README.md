# Memory

Persistent project context that the OS carries across sessions, so it works like a colleague who remembers your organisation rather than a stranger each time. This follows the two-tier memory idea from the AI Agent Development Guide: short-lived working context in a session, and a long-lived knowledge base here.

Treat these files as living records for a given engagement. Copy this folder into a project, fill it in, and keep it current. The skills draw on it: business-analysis and elicitation use the glossary and stakeholder directory, governance uses the decision register, and the orchestrator uses the project context to tailor its approach.

## Files

- `project-context.md`: the organisation, its goals, constraints, and preferences.
- `glossary.md`: the business glossary, so terms mean the same thing everywhere.
- `stakeholder-directory.md`: the standing list of stakeholders and how to engage them.
- `decision-register.md`: significant decisions and why they were made.

Keep every entry in the house style with no em dashes.
